## Суть урока
Инструменты области **«Экспорт»** на вкладке **«Главная»**: геометрия, изображение, видео, PDF (3D-анимация), анимация. Плюс как сделать красивое видео с полётом камеры (редактор видов + аниматор камеры).

## Экспорт геометрии
Выделить один/несколько компонентов → **Экспорт → Геометрия** → окно свойств превращается в «Экспорт планировки»: «экспортировать все компоненты» или «только выделенные», **формат файла** (напр. **STL** — открывается в сторонних CAD/анимационных средах) → «Экспорт» → «Сохранить».

## Экспорт изображения
**Экспорт → Изображение** → вокруг зоны моделирования красная область; справа настройки: **разрешение** (напр. 4K), портретная/ландшафтная ориентация или свои пропорции, **формат файла**, **режим рендера** (по умолчанию «Реалистичный с тенями» — самый красивый, менять незачем) → «Экспорт» → выбрать место.

## Экспорт PDF (3D-PDF с анимацией)
- Записывает **всю анимацию целиком**, окна рамки нет.
- Важные свойства компонента: **галочка «Спецификация»**, **«Наименование в спецификации»**, **«Описание в спецификации»** — описание попадает в PDF.
- Выбрать **шаблон**: только анимация; анимация + заголовок; + спецификация; + описание (самый полный). Задать **кадры в секунду** (стандарт ОК) и **заголовок** → **«Начать запись»** → место сохранения → записать (напр. полминуты) → **«Остановить» → «Сохранить»**.
- **Скорость записи = скорость симуляции**: что записали на ускорении, так оно и будет в PDF (нужна быстрее — поставь скорость симуляции быстрее).
- При открытии в Adobe Acrobat (бесплатный) спросит доверять ли документу — **«доверять только в этот раз»**, затем нажать вопросик (3D-область): в PDF проигрывается анимация, можно менять вид мышью, запускать/сбрасывать симуляцию, выбирать компонент в спецификации (он подсветится и приблизится) и читать его описание. Такой файл заменяет описание планировки, видео и чертежи, мало весит, удобно слать почтой.

## Экспорт анимации
Собственного просмотрщика пока нет — используется **Visual Components Experience** (режимы: 3D и VR). Запись: «Экспорт → Анимация» → кадры в секунду → «Начать запись» → расширение файла сменить на **.ecax**. Скорость записи любая: движения записываются, а в просмотрщике анимацию можно ускорять/замедлять; можно «прогуляться» в VR.

## Экспорт видео
Как изображение: рамка + настройки справа — **разрешение, кадры в секунду, видеокодек, качество**. «Начать запись» → место сохранения → симуляция идёт с вашими параметрами; **движение камеры мышью попадает в видео**; сбоку предпросмотр; «Остановить» → «Сохранить». Запись идёт сама, оставить компьютер можно.

## Красивое видео: редактор видов + аниматор камеры
1. **Редактор видов** (зона моделирования, слева по центру): занять камерой нужную позицию, выбрать **режим рендера** (напр. «Реалистичный»), нажать **«Добавить вид»**. Вид запоминает **положение камеры и режим рендера**; к нему можно вернуться из любой точки. Нужно заранее создать все виды (напр. общий, робот крупно, станок крупно, отъезд).
2. **Аниматор камеры** (вкладка/панель инструментов сверху): камера по очереди выполняет строки программы; галочка внизу включает/выключает программу. Строка = **вид + время + «лететь по сглаженной траектории»**. Время — момент, **к которому** вид должен быть достигнут: «Вид 1 — 0 с; Вид 1 — 10 с (стоим); Вид 2 — 25 с (летим 15 с); Вид 2 — 30 с; Вид 3 — 40 с…».
3. Поставить галочку программы → сбросить анимацию → галочку → закрыть окно.
4. **Настройки симуляции → «Время выполнения»**: вместо «Бесконечно» выбрать **«Пользовательский»** и ввести длительность (напр. 1 мин 35 с) → «Сохранить состояние»: симуляция сама закончится, и запись остановится.
5. Включить запись видео — движение камеры попадёт в ролик. Записывать можно на скорости симуляции ×10 (полторы минуты симуляции → 10 секунд видео).

## Практическое задание «Визуализация модели» (PDF урока 5)
1. Загрузить файл планировки, созданный ранее.
2. Открыть **Аниматор камеры**, сделать облёт между видами (виды создать заранее).
3. Сохранить результат как видео (**.mp4**) — результат должен быть похож на пример.
4. Сохранить **.rpro** и **.mp4**. (В домашнем задании по тексту урока нужно сделать каждый вид экспорта.)

## Лайфхаки и ловушки
- Хочешь ролик побыстрее — ставь скорость симуляции выше **до** записи (особенно для PDF).
- Забыл про «Время выполнения симуляции» — запись не остановится сама (бесконечно).
- Вид запоминает режим рендера: следи, чтобы во всех видах режим был нужный.
- Анимацию в PDF не запустить без «доверять документу».
- Для видео ставь разрешение поменьше, если нужно быстро проверить.


## Как это делает агент (проверено в R-Pro 2.2.2)
Видео: `app.Recorder = VC_RECORDER_VIDEO; app.RecordingFileName = "C:/путь/имя"` (БЕЗ расширения — программа допишет `.avi`), `app.Recording = True` сам запускает симуляцию; остановить `app.Recording = False` до её конца. mp4 делают ffmpeg-ом из avi.
Виды: `app.createView(u"Вид 1")` запоминает текущую камеру; аниматор камеры — компонент-элемент планировки `ViewAnimation`: `prog = item.Program; r = prog.MainRoutine; s = r.addStatement(VC_STATEMENT_VIEW); s.View = вид; s.Delay = секунды` и `VC_STATEMENT_DELAY`.
Не пишутся командами: изображение, 3D-PDF (`VC_RECORDER_PDF`), STL — только кнопками области «Экспорт».
