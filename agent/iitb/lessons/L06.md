## Суть урока
Сбор и вывод статистики симуляции. Демонстрационная планировка — «Доставка заказа со склада» (автоматический склад, конвейеры, мобильные роботы, два человека на ручной сборке, обмотка заказа, увоз грузоподъёмным роботом). Один инструмент **«Статистика»** (область «Статистика» на «Главной»).

## Создание листа статистики
1. Нажать **«Статистика»** → окно **выбора шаблона листа** (как расположены графики) → выбрать шаблон. Открывается лист с пустыми областями; для каждой области выбираем график. Уже созданные кем-то графики при открытии можно убрать.
2. **График по шаблону** (быстро): выбрать **компонент** (напр. человека) и **шаблон графика**, напр. **«Диаграмма состояний»**. Справа окно настройки: типы состояний (пользовательские и **системные**), данные **за последний интервал** или **за всё время симуляции**, галочка **«Определить цвета»** — цвет для каждого состояния (ожидание — жёлтый, занят — зелёный, заблокирован — красный и т.п.).
3. **Донастройка графика**: щёлкнуть по нему → в Свойствах: название, легенда (вкл/выкл), **тип графика** (столбец, круговая…; для состояний лучше круговая), серии данных (можно переименовать на русский). Лишние состояния (Repair, Failed, Break, Setup), которых нет у компонента, **удалять после прогона** — меньше шума. Состояния Ожидание/Занят/Заблокирован.
4. **График без шаблона**: выбрать вид (напр. «заполненный график»), задать название, включить видимость заголовка, настроить **серию данных**: в «Компоненты серии» — «+», найти компонент (напр. «Конвейер 25») и выбрать **свойство статистики** (напр. «Статистика → Количество частей, покинувших конвейер»). Проверка: запустить симуляцию — график растёт при выпуске заказов.
5. Лист назвать (напр. «Ручные операции»); кнопка **«+»** добавляет следующий лист.

## Интервал и время симуляции
- **Интервал** — как часто обновляются графики (по умолчанию раз в минуту); при «за интервал» это ещё и период, за который снимается статистика.
- **Настройки симуляции → «Время выполнения»**: вместо бесконечного — **«Пользовательский»** (напр. 1 час) и поставить высокую скорость, чтобы получить результат быстро. Графики обновляются в реальном времени.

## Вывод данных
- **Печать графика**: выбрать диаграмму → в области «Статистика» **«Печать графика»** → окно печати → принтер/«PDF» — получаем PDF.
- **Экспорт в Excel или CSV**: для каждого графика отдельный лист (напр. «Человек 1»): название свойства, значение, время (напр. t=360 с — ожидание 99,9 %). CSV/Excel нужны для анализа больших данных и поиска закономерностей (Excel или языки программирования).

## Как использовать статистику (пример из видео)
Человеки заняты ~50 %; гипотеза «второй человек не нужен». Эксперимент: за 53–55 мин собрано 14 заказов; второго человека **удалили с планировки**, перезапустили — первый загружен больше (52 % → выше), но за час 14 заказов в одиночку не собрал. Вывод: второй человек нужен, либо менять планировку/логистику, чтобы выйти на прежние показатели с одним. **Настроенный лист статистики сохраняется** — достаточно изменить планировку и запустить симуляцию заново, чтобы получить новые показатели.

## Практическое задание «Создание листа статистики» (PDF урока 6)
1. Область «Статистика» → инструмент «Статистика» → выбрать **шаблон листа**.
2. Загрузить планировку, созданную ранее.
3. Создать **график по данным модели**.
4. Экспортировать лист статистики в **PDF**.
5. Сохранить **.rpro** и **PDF** результата.

## Лайфхаки и ловушки
- Шаблонный график делается парой кликов — не создавай вручную то, что есть в шаблонах.
- Выбирай «за всё время симуляции» для итогового отчёта, «за интервал» — для динамики.
- Удали из графика состояния, которых нет, иначе путаница в легенде.
- Статистика считается только после прогона симуляции — запускай на ускорении с заданным временем выполнения.


## Как это делает агент (проверено в R-Pro 2.2.2)
Дашборд: `tab = app.Dashboard.createTab(...)`, `tab.clearLayout()`, `chart = tab.createChart(плитка, VC_CHARTTYPE_PIE|LINE|COLUMN|BAR, True)`, серия: `s = chart.addSeries(); s.Property = beh(компонент, "Statistics").getProperty("BusyPercentage")` (ещё `PartsExited`, `Utilization`), цвет `s.Colors = [vcVector...]`. Данные — `chart.DataRows`. Интервал выборки `app.Simulation.Statistics.SamplingInterval`.
Часовой прогон: `app.Simulation.SimSpeed = 20.0` и `run_for` на 3600 с. CSV/PDF с листа пишут из `DataRows` внешним кодом.
