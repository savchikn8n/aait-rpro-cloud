## Суть урока
Рабочая область **«Моделирование»** — создание собственных компонентов. Пример: **позиционер** (линейная ось с кареткой), на который ставится робот, и который робот сам двигает как внешнюю ось.

## Создание компонента и геометрии
1. Область «Компонент» → **«Создать»** — появляется «Новый компонент» (стандартные свойства: наименование, материал, спецификация, категория).
2. Окно **«Диаграмма компонентов»** слева: **верхняя область** — свойства, поведение и **структура** (звенья); **нижняя** — **геометрия** выбранного звена.
3. Выбрать корневое звено → **«Элементы»** (раздел «Геометрия») → простая геометрия, напр. **параллелепипед** (также цилиндры, сферы). В нижней области виден элемент; **скопировать/вставить** — получается дочерняя геометрия (можно сделать независимой или дочерней: из таких элементов складывается геометрия).
4. Свойства элемента геометрии: **размеры** (длина/ширина/высота у параллелепипеда), **материал**, **координаты** (смещение по осям). Пример: «Основание» 1500 мм; два дочерних бруска (высота 20, ширина 400, длина 1500; смещены по Y на 100 и на 400 мм) → «Направляющие». Имена элементам давайте осмысленные. Группируйте геометрию для дальнейшей работы.
5. **Сохранение:** «Сохранить» / «Сохранить как» → название, **описание**, **тип компонента** (напр. позиционер для робота), автор, **версия** (галочка «автоматически увеличивать»). Компонент становится отдельным файлом и загружается как из каталога.

## Структура: звенья
- Структура строится из **звеньев**; по умолчанию одно корневое. Звенья делят компонент на части, которые могут **двигаться друг относительно друга**.
- Кнопка **«Создать звено»** (Link_1) — например, подвижная каретка. Геометрии у нового звена нет: выбрать узел, **сместить его систему координат**, «Элементы» → параллелепипед (напр. 300 мм), материал.

## Свойства и поведение
- **Свойства** — переменные с типом данных (real и др.); **поведение** — набор действий компонента.
- Добавить свойство типа **real**, имя (напр. «ДлинаКаретки»), единицы (мм), значение (200), **ограничения** (от 200 до 500). Пользователь видит его среди свойств компонента.
- **Параметризация геометрии:** скопировать имя свойства и вписать его **как выражение в поле размера** (длина каретки = ДлинаКаретки) — теперь значение свойства меняет геометрию.

## Движение звена
- Выбрать звено → **Joint type** (по умолчанию неподвижное): вращательное, **поступательное**, вращательное ведомое, поступательное ведомое, пользовательское. Для каретки — **поступательное**, ось движения (стрелка показывает; напр. **+X**), имя оси и **пределы**: от 0 до (1500 − длина каретки). Проверка: инструмент «Взаимодействие» — каретка ездит в пределах.
- **Контроллер:** «Поведение» → **сервоконтроллер** (Servo Controller) → указать, какими осями он управляет (ось звена **J1**). Появляется свойство **J1**, куда пользователь вводит значение (за пределы не даст). Теперь компонентом можно управлять свойствами и **ссылаться** на них. В «Программировании → Взаимодействие» эта ось видна так же, как оси робота.

## Мастер «Позиционер» (шаблоны поведений)
В области «Моделирование» есть **«Мастер»** с 7 шаблонами (позиционер, конвейер, датчик, станок…). Для позиционера: выбрать **«Позиционер робота»** (есть ещё «позиционер заготовки»), **звено фланца** — конечное подвижное звено, к которому крепится робот (каретка) → «Применить». Появилось поведение **Mount Interface** — готовое подключение робота. **Если рамка интерфейса создана неверно — сместить её вручную в центр каретки.** Сохранить как позиционер.

## Подключение робота
Каталог → робот → **PnP** на позиционер. В «Программировании → Взаимодействие» у робота кроме шести осей появилась **седьмая — внешняя** (ось позиционера). Робот программируется как обычно: повернуть все оси (и внешнюю) в позицию → добавить точку. Робот сам двигает позиционер.

## Дополнительно
- Не обязательно использовать шаблоны: можно собрать уникальный компонент из наборов поведений.
- Есть поведение **«Скрипт Python»** — вы программируете свои собственные поведения (описано в справке Python API и Python 2.7) — можно создать «буквально что угодно», наделив геометрией.
- Инструменты геометрии (упростить, разрезать, поменять материал, наложить картинку) — см. справку.

## Практическое задание «Создание позиционера» (PDF урока 10)
1. Вкладка МОДЕЛИРОВАНИЕ → создать геометрию разделом **«Элементы»** (сгруппировать).
2. Выделить часть геометрии, которая движется → зарегистрировать как **отдельное звено**.
3. В свойствах компонента — тип движения звена (корректные свойства движения).
4. Свойство: выбрать тип, **добавить новое свойство**, указать значения и имя; использовать для **параметризации геометрии**.
5. **Контроллер:** в свойствах элементов компонента задать контроллер (один для всех).
6. Интерфейс подключения к роботу: **Мастер → Позиционер** (рамку при необходимости сместить в центр каретки).
7. Подключить робота к позиционеру, написать небольшую программу движения робота на позиционере.
8. Результат: **.rpro**, запись видео, **.mp4**.

## Лайфхаки и ловушки
- Геометрию у каждого звена создаёшь отдельно: сдвинь систему координат узла.
- Пределы движения лучше задавать выражением от свойств (1500 − длина).
- Новое свойство нужно «подвесить» к размеру — само оно ничего не делает.
- Сохраняй после каждого этапа (потом проверяй в «Взаимодействии»).


## Как это делает агент (проверено в R-Pro 2.2.2)
Свой компонент: `comp = app.createComponent(); comp.Name = _b(u"Позиционер")`; геометрия `comp.RootFeature.createFeature(VC_BLOCK, "имя")` (Length/Width/Height — строки-выражения, можно `"CarriageLength"`); свойство `comp.createProperty(VC_REAL, "CarriageLength")`; звено `n = comp.createNode(VC_NODE, "Carriage")` (БЕЗ типа первым аргументом вернёт None!); `n.JointType = VC_JOINTTYPE_TRANSLATIONAL; n.Dof.AxisType = VC_JOINTAXIS_PLUS_X; n.Dof.Name = "J1"; n.Dof.MinLimit = "0"; n.Dof.MaxLimit = "1500 - CarriageLength"`; сервоконтроллер `servo = comp.createBehaviour(VC_SERVOCONTROLLER, "ServoController"); n.Dof.Controller = servo`. Мастер «Позиционер» = `VC_ONETOONEINTERFACE` «MountInterface» + `VC_HIERARCHYFIELD` + `VC_JOINTEXPORTFIELD` (см. PositionerWizard.py).
Сохранить компонент: `comp.save(_b(u"file:///C:/путь/имя.rpro"))` — обычный путь молча ничего не пишет.
