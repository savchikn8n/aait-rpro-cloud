## Суть урока
Обратный процесс к паллетированию (урок 15): на уже созданном процессе снимаем банки с поддона. Ключевое выражение — **Detach («Открепить»)**.

## Шаги
1. **Клонировать** имеющийся на планировке конвейер; **удалить** с него узел процесса и поставить **новый «Узел процесса»** из библиотеки; **PnP** — подключить конвейеры друг к другу. Добавить ещё один узел процесса — **место, куда отгружаем детали** (расположить).
2. Назвать процессы: «2», «3» (первый — прежний).
3. **Процесс №2:** принять поддон (**TransportIn**, переменная поддона) → выражение **Detach («Открепить»)** — открепить банку от поддона, поставить галочку **«Отсоединить многие»** (иначе отсоединится только одна банка, а нужно все) → **несколько TransportOut**: **один для банок**, **один для поддона** (дополнительный TransportOut «для отгрузки цилиндров»/банок).
4. Транспортные связи: сначала **процесс 1 → процесс 2 по конвейеру**, затем **процесс 2 → процесс 3**. Проверить: сначала детали открепляются, потом можно перемещать **каждую деталь на поддоне по одной**, в конце — сам поддон.
5. **Исполнитель:** чтобы детали не «летали», добавить **«Человек (Иван)»** и **«ТК человека»** из библиотеки; **интерфейсами** подключить ресурс к транспортному контроллеру; **в свойствах транспортной связи заменить исполнителя** на человека. Можно поставить того же человека и на загрузку — тогда он и паллету загружает, и выгружает.

## Практическое задание «Депаллетизация» (PDF урока 16)
Создать процесс депаллетизации: конвейеры (клон, PnP) → Detach в процессе №2 (настроить свойства) + дополнительный TransportOut → транспортные связи → ресурс (человек + ТК), исполнитель связи.

## Лайфхаки и ловушки
- «Отсоединить многие» не включил — снимается одна банка.
- После Detach у каждой банки и у поддона свои TransportOut — не забудь оба.
- Человек не подключён к ТК через «Интерфейсы» — детали «летят».


## Как это делает агент (проверено в R-Pro 2.2.2)
Депаллетизация: второй узел после конвейера: `TransportIn Source="From Container"` → `DetachProduct(ProductVariableName="Pallet", DetachedVariableName="Can", DetachMany=True, AcceptAllProductTypes=True)` → `TransportOut "To Next Process"` для банок (на «Процесс утилизации»/приёмку) → `TransportOut "To Container"` для пустого поддона. Банки переносит человек: «ТК человека» + «Human (Ivan)», зона прохода `crew_area(тк, AREA, 1500)`, связи `link(подача, узел1, тк, g)` и `link(узел2, приёмка, тк, g)` (старые связи-«перелёты» удалить `ts.deleteTransportLink(l)`).
