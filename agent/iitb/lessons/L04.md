## Суть урока
Область **«Чертёж»** нужна для технической документации к планировке без перехода в сторонние CAD. Инструмент не основной, дополнительный. Здесь: загрузка рамки, создание видов, размеры, аннотации, спецификация, экспорт/печать.

## Порядок работы
1. **Рамка:** инструмент **«Загрузить шаблон»** → в свойствах поле **«Шаблон»** (напр. рамки А0…А4) → **«Импорт»** → рамка появляется. Выбрать рамку щелчком — **свойства** заполняют основную надпись (обозначение детали, название и т.д.; видно в рамке).
2. **Масштаб:** свойство рамки **«Масштаб»** (по умолчанию **1:100**) определяет масштаб, с которым загружаются виды. Менять **до** создания видов (напр. на 1:50) — потом виды генерируются в нужном масштабе.
3. **Виды:** область **«Создать вид»** — один из **шести стандартных видов** (сверху, спереди, сзади…) одним нажатием. Вид рисуется один раз **в момент нажатия** — нет привязки ни к текущей модели, ни между видами (не как в CAD). Выравнивание видов — вручную, по **координатам** (напр. оба вида поставить по X = −275).
4. **Свой вид:** **«Выбрать вид»** → откроется зона моделирования → включить **ортогональную проекцию**, выбрать нужный вид на пирамидке (напр. изометрия), выделить область → «ждём создания чертежа». Так делают изометрию или показывают часть планировки.
5. **Размеры:** инструмент размеров, удобная функция **«Тип привязки»** (напр. «границы») — быстрые габаритные размеры; есть угловой размер. Всё правится через **Свойства** (размер шрифта и т.д.).
6. **Аннотации:** текстовая аннотация и ссылки на компоненты (напр. «пульт управления станка»); **круглая аннотация** работает в связке со спецификацией — указываешь на робота, ему присваивается номер позиции.
7. **Спецификация:** вручную или автоматически кнопкой **«Создать»** (сама ставит аннотации-позиции по всем существующим видам и строит таблицу: поз., наименование, количество).
8. **Экспорт/печать:** **«Экспорт»** (разные форматы, проводник → файл, открывается в сторонней программе) или **«Печать»** (окно печати, предпросмотр; печать в PDF → получаем PDF-файл).

## Спецификация: правила
- Чтобы компонент попал в спецификацию, у него в свойствах должна стоять **галочка спецификации**.
- В поле **«Наименование в спецификации»** можно ввести любое имя — оно и будет в таблице.
- Чтобы изменения применились к уже созданной спецификации: **выбрать её → очистить → создать заново**.

## Практическое задание «Создание чертежа» (PDF урока 4)
1. Область «Чертёж» → «Загрузить шаблон» → загрузить рамку.
2. Загрузить процесс, созданный на прошлом уроке (планировку урока 3), создать один из стандартных видов.
3. Добавить спецификацию и аннотации к видам.
4. Экспортировать чертёж в **PDF**.
5. Сохранить **.rpro** и **PDF** чертежа.

## Лайфхаки и ловушки
- Меняешь масштаб после создания видов — они не пересоздаются: удали виды и создай заново.
- Спецификация не обновилась после смены имён — очистить и создать заново.
- Для «своего вида» обязательно включить ортогональную проекцию.
- Печать «в PDF» — самый быстрый способ получить PDF чертежа.
