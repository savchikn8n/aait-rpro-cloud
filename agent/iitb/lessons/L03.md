## Суть урока
Как построить производственный процесс на шаблонных компонентах. Идея: **операции** (компоненты процесса) содержат шаблонную логику между ними перемещается **продукция**; перемещает её **исполнитель** (человек, робот, мобильный робот, кран…); исполнителем управляет **транспортный контроллер** (менеджер исполнителей). Исполнители связаны с транспортным контроллером, а контроллер — с операциями.

## Коллекции каталога для процессов (префикс «МП» = моделирование процессов)
- **МП Компоненты процессов** — кольца с значками, у каждого шаблонная логика: «Процесс с конвейера» (перехватить деталь с конвейера и отдать работнику), «Процесс к конвейеру» (получить от работника и положить на конвейер), **«Узел процесса»** — универсальный процесс с минимальной логикой, которую можно менять; «Устройство подачи» — тоже вид процесса, сразу выдаёт продукцию на конвейер.
- **МП Транспортные контроллеры** — цилиндры со значком; значок показывает, какими исполнителями контроллер управляет (напр., «Транспортный контроллер робота»).
- **МП Ресурсы** — сами исполнители: человек, человек на погрузчике, мобильный робот, робот, экран; **подъёмные краны**, приспособления, ограничивающие/меняющие работу исполнителей.
- **Продукты и контейнеры** — готовая продукция, не надо моделировать: коробки, паллеты, двери, вёдра, бутылки; внизу — «Этап токарной обработки 1/2».
- **Роботы** — тоже исполнители, хотя без префикса МП. Захват робота — коллекция «Роботы (инструменты)».

## Шаги создания процесса
**Шаг 0. Загрузить компоненты** (вкладка «Главная»): устройство подачи → обычный конвейер (подключить PnP; можно запустить симуляцию и убедиться) → «Процесс с конвейера» (подключить PnP к концу конвейера; потом его можно двигать вдоль конвейера, в пределах конвейера; продукт останавливается на нём) → копия конвейера → «Процесс к конвейеру» (в начало второго конвейера) → транспортный контроллер робота (сбоку, повернуть) → шарнирный робот, придвинуть к процессам → захват из «Роботы (инструменты)» (размер захвата — в свойствах инструмента, уменьшить под деталь) → станок (напр. токарный, развернуть и поставить рядом с роботом) → детали «Этап токарной обработки 1» (заготовка) и «2» (готовое изделие), отставить в сторону.

**Шаг 1. Регистрация деталей** (область **Процесс → Детали**, окно «Редактор типа деталей»; если там уже что-то настроено — удалить):
1. Кнопка **«+»** → «Добавить группу процессов» и «Добавить тип детали» (два раза).
2. Переименовать группу (напр. «Токарная обработка»), типы — «Заготовка», «Готовое изделие».
3. Выбрать тип → справа в Свойствах кнопкой «указать» дать **ссылку на компонент** (компонент в зоне подсветится обводкой). Так деталь может создаваться и распознаваться процессом.
4. Устройство подачи → раздел свойств **Product Creator**: тип **«Одиночный»**, **Интервал** (напр. 20 с), **Деталь** = «Заготовка». Теперь вместо цилиндров по конвейеру едет нужная деталь. Так создаётся любой компонент — коробка, паллета и т.д.

**Шаг 2. Технологический процесс** (область Процесс; кнопка «Операции» показывает все операции — в примере четыре: FromConveyor, ToConveyor, станок и т.п.; кнопка «Процесс» — те же операции без названий видео-точек):
- В операциях настраиваются сами операции, в **Процессе** — **последовательность операций**. Внизу вместо «Вывод» появляется **«Редактор технологического процесса»** со списком групп.
- Для группы: **«+»** или ПКМ → добавить шаг → выбрать операцию. Пример: 1) FromConveyor → 2) робот переносит деталь на станок/обработку → 3) ToConveyor. Порядок можно двигать курсором; ПКМ — удалить/вырезать/копировать.
- Группа процессов определяет, **какая продукция** идёт по этой последовательности; другая логика — создать новую группу и новую последовательность.

**Шаг 3. Транспортные связи** — без них деталь знает, куда ей нужно, но переместиться не может:
- Выбрать начальную операцию (напр. FromConveyor) → выбрать **исполнителя** (напр. робот) → выбрать операцию-цель: создаётся связь со стрелкой, **посередине — иконка исполнителя** (она же видна внизу в редакторе). Так же делается вторая связь.
- Не выбрали исполнителя — система предложит его сама (может ошибиться).
- Исправить: удалить связь (выбрать, «Удалить») либо **«Изменить транспортный контроллер»** (ПКМ или двойной щелчок + окно свойств → поле «Исполнитель»).
- **Ловушка:** если исполнитель сбился на «полёт по воздуху» — деталь будет лететь по воздуху вместо переноски; выберите робота.

**Шаг 4. Логика операций** — не обязательна на этом уроке: берётся шаблонная; как заставить станок выдавать готовое изделие — в следующих уроках.

## Практическое задание «Создание процесса» (PDF урока 3)
1. Настроить технологические процессы: в редакторе две группы — **#1: FromConveyor → ToConveyor** и **#2: FromConveyor → «Параметрический вертикальный фрезерный станок» → ToConveyor**.
2. Создать транспортные связи (исполнитель — робот).
3. Сохранить как .rpro (ФАЙЛ → Сохранить как).

## Лайфхаки и ловушки
- Хочешь проверить подключение — запусти симуляцию сразу после PnP.
- «Процесс» без детали-ссылки ничего не создаст: сначала регистрируй типы деталей.
- Все исполнители должны быть привязаны к транспортному контроллеру, иначе связь без исполнителя.
- Если операции загрузились в неправильном порядке — перетащить курсором.
