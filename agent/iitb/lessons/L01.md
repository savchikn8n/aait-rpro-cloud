## Суть урока
Обзор программы «Р-Про» (Рациональное производство, версия 2.1/2.2, rpro.digital): для чего она нужна, как устроено окно, как работать с каталогом и как загрузить компонент в зону моделирования. Программа нужна для цифровых двойников, моделирования процессов и офлайн-программирования роботов; поддерживает собственные инструменты (скрипты/плагины).

## Устройство окна
- В центре — **зона моделирования** (3D-вид, здесь живёт планировка).
- Вокруг — **окна** (Каталог, Свойства, Вывод, Дерево построения…). Окна можно менять по размеру, закреплять, закрывать, перетаскивать курсором; для каждой рабочей области раскладка своя.
- Сверху — **рабочие области** (вкладки), под ними — **инструменты выбранной области**.
- Справа вверху ленты — блок «Окна»: **«Восстановить окна»** (вернуть раскладку по умолчанию) и **«Показать»** (галочками включить/выключить окна).

## Рабочие области
| Область | Что в ней |
|---|---|
| **Главная** | Загрузка компонентов, создание планировки, экспорт презентационных материалов, считывание статистики и её экспорт |
| **Процесс** | Три инструмента: **Детали** (регистрация деталей, заготовок, инструментов — любых материальных потоков), **Операции** (последовательность действий в каждой операции), **Процесс** (последовательность операций: что откуда и куда) |
| **Моделирование** | Создание своих компонентов: простая/сложная геометрия, свойства, поведение — свой робот, конвейер, камера |
| **Программирование** | Программирование роботов: загрузить робота, написать программу, перемещать, ввод в эксплуатацию; проверка программы (столкновения, физичность), выгрузка на реальное оборудование |
| **Чертёж** | Техдокументация: стандартные/нестандартные виды, аннотации, спецификация, сохранение/печать |
| **Помощь** | «Задайте вопрос» (письмо в техподдержку), справка, файлы Python API и Python 2.7 (для программирования, вне курса). В общей справке: поддерживаемые CAD-форматы, «Начало работы», «Пользовательский интерфейс» |

## Каталог (окно слева)
Состоит из двух частей: слева **коллекции**, справа **содержимое** выбранной коллекции (компоненты, планировки, файлы).
- Шесть папок создаются автоматически: «Все модели», «Общедоступные модели», «Мои модели» и др.
- **Фиолетовая папка — источник**: в ней лежат сами файлы компонентов/планировок.
- **Синие — «умные коллекции»**, система строит их сама: **«Модели по Типу»** (тип → производитель → конечная коллекция) и **«Модели по Производителю»** (производитель → тип → коллекция). До робота ABB можно дойти и так, и так — это одна и та же коллекция.
- Внизу — фильтры «Компоненты» и «Планировки».
- Каталог можно обновлять, добавлять коллекции и источники — см. справку.

## Загрузка компонента
- **Двойной щелчок** или правая кнопка → **«Открыть»** — компонент появляется в стандартном месте.
- **Перетаскивание** мышью — компонент встаёт туда, куда отпустили.
- Одно оборудование = **компонент** (например, один конвейер). Несколько компонентов в зоне моделирования при сохранении = **планировка**; расширение файла одинаковое, различие только по содержимому.

## Практическое задание (PDF «Задание 1»: Kuka 40 PA)
Найти робота тремя способами и загрузить в зону:
1. **Окно поиска** в каталоге → ввести название → выбрать модель → перетащить в нужное место (зажав ЛКМ) либо ПКМ → «Открыть».
2. **«Модели по Производителю»** → Kuka → «Роботы» → модель.
3. **«Модели по Типу»** → «Роботы» → Kuka → модель.

Результат: вкладка **ФАЙЛ** (или кнопка быстрого сохранения, или **Ctrl+S**) → **«Сохранить как»** → заполнить поля. Бежевым выделена опция **«Сохранить компоненты»** — сохраняет вместе все входящие компоненты; включать, если файлом надо поделиться (иначе элементы потеряются). «Обзор» → выбрать место → имя файла **«Урок_1»**.

## Лайфхаки и ловушки
- Хочешь файл «для передачи» — обязательно «Сохранить компоненты».
- Двойной щелчок кладёт компонент в стандартное место, перетаскивание — в точку курсора.
- Пока не разобрался с инструментом — открой справку прямо в программе (она работает параллельно с софтом).
- К тесту после урока прилагается файл или Google-форма.
