## Суть урока
Что такое промышленный робот в Р-Про и как подготовить ячейку (ввод в эксплуатацию) перед написанием программы: поставить робота на опору, закрепить инструмент и **настроить системы координат BASE (база) и TOOL (инструмент)**.

## Что такое робот
- Робот = **промышленный манипулятор** (шестиосевой: основание + 6 звеньев, каждое поворачивается относительно предыдущего) + **шкаф управления** (физически исполняет программу, программа передаётся на него с пульта или из ПО) + интерфейс программирования. В Р-Про всё это **в одном компоненте** — пульт и шкаф подгружать не надо.
- Всё, что установлено на фланец робота (сварочная головка, захват, вакуумная чашка), — **инструмент** (рабочий орган), к самому роботу не относится. Его кончик/рабочая точка — то, что перемещают.
- **Программа робота** — строки, выполняемые по очереди (движения и логические действия); язык зависит от производителя.

## Системы координат (разобраться по справке: раздел 2.3, поиск «Tool Central Point, Base Tool»)
Робот пересчитывает 6 осей в декартовы координаты через две системы:
- **BASE (база, «основная»)** — в ней задают положение точки (напр. X=500, Z=1000): где нулевая точка и куда направлены оси. Для каждой рабочей зоны/стойки своя база.
- **TOOL (инструмент, TCP — Tool Central Point)** — какую точку и с какой ориентацией двигаем (центр вакуумной чашки, кончик электрода).
- Для каждого инструмента и каждой рабочей зоны систему координат настраивают отдельно. Доступно **16 баз и 16 инструментов**.

## Сборка ячейки (практика урока)
1. Каталог → **«Роботы (опоры)»** → простая подставка R-Pro; любой робот из «Роботы» (работают одинаково); PnP — установить на подставку.
2. Инструмент: **«Роботы (инструменты)»** → вакуумный захват с одной чашкой, PnP — на фланец робота (дальше двигается вместе с роботом).
3. Рабочие места: ещё одна подставка (выше), две стойки рядом с роботом; цвет платформ — свойство цвета; объект манипулирования — банка на платформе.

## Настройка баз и инструмента (область «Программирование»)
1. Выбрать робота → справа внизу вкладка **«Взаимодействие»**: свойства **базы** и **инструмента**.
2. **База:** выбрать одну из 16 (первую) → кнопка с **шестерёнкой** → видна система координат; по умолчанию она в центре основания робота — **вынести** её на нужный край стойки (**BASE_1** — у первой стойки, **BASE_2** — аналогично у второй). Выбрав базу, видим где она.
3. **Инструмент:** выбрать Tool 1 → шестерёнка → стандартная точка — центр фланца, а надо **центр вакуумной чашки** → вынести точку вперёд и поставить по центру чашки (можно переименовать; прочие параметры — в справке).
4. После этого роботом можно управлять за эту точку: её смещают — робот сам подстраивает 6 осей (вручную каждую ось двигать не нужно).
5. **Относительные координаты:** по умолчанию координаты точки «странные» (мировые). Переключить систему координат на **относительную (в базе)** — показывает координаты относительно вашей базы: напр. (150, 150, 120). Их можно **ввести вручную** (измеренные рулеткой в реальном мире) — робота перемещать в точку при программировании не обязательно.

## Практическое задание «Подготовка ячейки к программированию» (PDF урока 8)
1. Загрузить элементы из библиотеки (пример ниже в PDF: робот + опора + инструмент + стойки + продукт + конвейер + сенсор/мотор сигналов).
2. **Подключить сигналы:** `SensorBooleanSignal` → **вход робота**; **выход робота → `MotorSignal`**.
3. Настроить систему координат инструмента **TOOL_1**.
4. Настроить основные системы координат **BASE_1, BASE_2**.
5. Сохранить **.rpro**.

## Лайфхаки и ловушки
- Вносить размеры в точку надо в **относительной системе** — тогда числа понятны и измеримы.
- Перед программированием всегда: база(ы) → инструмент → проверка точки (двигаешь точку — робот подстраивается).
- Инструмент поменяли — переделай TOOL.


## Как это делает агент (проверено в R-Pro 2.2.2)
Ячейка робота: робот на «Параметрической тумбе» (PnP по интерфейсу `Tool`/`EOAT_MountInterface` для захвата), конвейеры на `InInterface`/`OutInterface`, двигатель и датчик конвейера. Сигналы робота: `beh(робот, "Inputs").connect(102, beh(датчик, "SensorBooleanSignal"))`, `beh(робот, "Outputs").connect(105, beh(двигатель, "MotorSignal"))`. Инструмент называется `TOOL[1]`, базы `BASE_1`, `BASE_2`. Положение датчика вдоль ленты — свойство `ComponentPathSensor.Distance` (присвоение `PositionMatrix` игнорируется).
