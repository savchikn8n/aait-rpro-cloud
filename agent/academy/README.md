# Academy → реестр знаний агента

Visual Components Academy (https://academy.visualcomponents.com): 265 уроков и 7 вебинаров.
R-Pro — это Visual Components 4.x под своим именем, поэтому приёмы из обучающих материалов в ней
работают. Видео смотреть дорого по лимитам подписки, поэтому агент учится по **тексту**: субтитры
роликов и PDF-мануалы → конспект (Haiku) → короткий русский урок → **единый реестр знаний**.

Обзор для людей: [docs/14-obuchenie-po-urokam-academy.md](../../docs/14-obuchenie-po-urokam-academy.md),
лайфхаки списком: [docs/12-lajfhaki-rpro.md](../../docs/12-lajfhaki-rpro.md).

## Что где лежит

После обработки в папке остаётся только это (рабочие папки существуют только во время запуска):

| Что | Где |
|---|---|
| **Реестр знаний**: по строке на урок (русский урок, английский конспект, метаданные, применимость, вошёл ли в базу агента, модель, дата, оценка аудита) | `registry/lessons.jsonl` |
| Исходные тексты, из которых сделаны уроки (транскрипт с минутами или текст PDF, сырые субтитры) | `registry/sources.jsonl.gz` |
| Отчёты оценки качества (судьи, A/B поиска, сквозной тест) | `registry/audit/` |
| Поиск агента — строится из реестра, читается `agent/kb.py` | `../kb/academy_chunks.jsonl` |
| Состояние по каждому уроку | `STATUS.md` |
| Каталоги портала | `catalog.json` (уроки), `catalog_extra.json` (вебинары) |
| Русские названия интерфейса R-Pro (EN→RU, из ресурсов программы) | `uiterms.json` — от него зависит и `agent/quickref_build.py` |
| Единый промт запуска модели | `prompts/HAIKU_RUN_ALL.md` |
| Промпты оценки качества (для повторения аудита) | `prompts/judge_*.md` |

Рабочие папки (в `.gitignore`): `pending/` (входы, пачки, результат запуска, скачанные PDF),
`transcripts/`, `digests_en/`, `digests_ru/`, `work/`. Их переносит в реестр и убирает
`academy_consolidate.py`; руками удалять не нужно.

## Как обработать новые материалы

1. **Достать вход.** Видео и вебинары: захват субтитров через Chrome (`grab.js`, `receiver.py`, ниже).
   Документные уроки: `python academy_pdfs.py links`, затем `fetch --yes` (скачивает PDF с
   academy.visualcomponents.com в `pending/pdf/`; без `--yes` только показывает план и размер).
   Новые уроки сайта: `python academy_crawl.py`, вебинары: `python academy_crawl_extra.py`.
2. **Подготовить входы:** `python academy_prep_pending.py` → `pending/lessons/`, `pending/terms/`,
   `pending/batches/`, `pending/index.json`. Берёт всё, чего ещё нет в реестре.
3. **Запустить модель:** дать ей `prompts/HAIKU_RUN_ALL.md`. Она сама пишет конспекты и уроки в
   `pending/out/{en,ru}/`, проверяет их, сливает в реестр и чистит рабочие папки.

Что делает слияние — `python academy_consolidate.py` (без флагов только показывает план):
`--apply` переносит принятые уроки в реестр, архивирует исходники, пересобирает поиск агента и
проверяет результат; `--apply --clean` дополнительно убирает рабочие папки, но только если проверка
прошла, всё подготовленное уже слито и все непустые транскрипты заархивированы. Плохие уроки
(нет разделов, нет строки применимости, остались метки времени) в реестр не попадают: скрипт
называет их, они остаются в `pending/out/` для переделки.

Состояние: `python academy_status.py` (→ `STATUS.md`). Проверка текстов: `python validate_digests.py en|ru`.

## Один урок: найти, сверить, исправить

Агент дал плохой совет — в трассировке чата есть строка «→ справка подложена: Уроки Academy / …».

```
python academy_lesson.py find <часть названия>
python academy_lesson.py show <slug> --source     # русский урок + исходный текст для сверки
python academy_lesson.py set <slug> <файл.md>     # заменить русский урок, пересобрать базу агента
```

## Как агент использует уроки

`kb.py` читает `academy_chunks.jsonl` вместе со справкой; `rpro_help(source="уроки")` ищет только по
урокам; `/справка`, `/термин`, `/совет` (agent/quickref.py) тоже опираются на эти данные. Уроки входят
в общую выдачу и в автоподстановку по умолчанию; выключить: `RPRO_KB_ACADEMY=0`. Защиты: в первых
двух фрагментах не больше одного урока (иначе уроки вытесняют справку), оценки уроков умножаются на
`RPRO_KB_ACADEMY_WEIGHT` (0,85), при попадании урока модели сказано сверять кнопки со справкой и
писать код только на Python 2.7. Уроки про Python 3 API и «не применимые к R-Pro» в базу не
попадают (`in_kb: false` в реестре). Имена Python-API в уроках сверены с `agent/kb/api_index.json`:
регистр исправляется автоматически, имена, которых нет в API R-Pro, помечены ⚠.
`retrieval_probe.py` показывает, что находится на 25 вопросах новичка; `e2e_probe.py <0|1>` задаёт 4
вопроса настоящей модели без уроков и с ними; `academy_judge_prep.py` готовит материалы для оценки.

## Что показала оценка

- **Поиск (25 вопросов, судья Sonnet):** средняя релевантность 1,44 → 2,32 из 3; лучше в 11
  вопросах, хуже в 2 (урок вытеснил профильную справку).
- **Верность (16 случайных уроков, два судьи):** около 3,2 из 5, полезность около 2,8; все 16 «fix».
  Типичные ошибки Haiku: придуманные «ловушки», перепутанные кнопки, потерянные шаги, имена API,
  восстановленные на слух, смесь русских и английских названий. Это подсказки, а не гарантия.
- **Живая модель (4 вопроса, qwen3:8b, без моста R-Pro):** паллетизация — связный ответ из урока
  вместо ответа мимо; «скрыть компонент» без уроков — таймаут 10 минут; «кнопка-свойство» — модель и с
  уроком сочинила код. 8B не следует фрагментам надёжно: уроки дополняют готовые команды в коде.
- **Второй прогон (52 урока, Haiku 5.5, 2026-10-08):** все приняты слиянием с первого раза; русские
  уроки короче (медиана 2101 знак, максимум 2504); все идентификаторы API есть в исходнике; аудит 8
  уроков — верность около 4,25 из 5 (у первого прогона около 3,2), полезность около 3,1;
  `mqtt-client-tutorial` (функция 5.0) переведён в «не применимо».
- Код есть в 56 из 218 первых уроков; для остальных ошибка — это неточная кнопка, видимая сразу.

## Захват субтитров через Chrome

С корпоративного IP YouTube блокирует `yt-dlp`, `youtube-transcript-api` и встроенный браузер;
работает только Chrome пользователя с расширением Claude in Chrome (он вошёл в аккаунт сам).

1. `python receiver.py` в фоне (порт 8799; **порт 8765 занят мостом R-Pro**).
2. Открыть любой ролик на youtube.com, вставить `grab.js` в `javascript_tool` (`eval` запрещён
   Trusted Types) и запустить `grabAll([...id...])` без `await`; результат — `transcripts/<id>.json`.
3. Слежение — по файлам на диске. Окно Chrome должно быть на переднем плане: в фоновой вкладке
   таймеры замедляются, и длинные вебинары ползут.

Ловушки:
- После SPA-перехода URL меняется **раньше** плеера и панели, поэтому `grab.js` ждёт, пока плеер сам
  назовёт нужный `video_id`, сверяет длительность с последней меткой транскрипта и отсекает дубли. Без
  этого однажды в базу попал чужой текст (`model-a-raycast-sensor`; перезахвачен 2026-10-08).
- У YouTube **две вёрстки панели транскрипта**: `ytd-transcript-segment-renderer` и
  `transcript-segment-view-model`. Старый селектор на новой давал «пустой транскрипт», что выглядело как
  «субтитров нет» (так «пропали» шесть вебинаров и `teach-trace…`). `grab.js` читает обе.
  «Пустой транскрипт» — не доказательство, что субтитров нет.
- Клик по `<a href>` на странице — полная перезагрузка и гибель скрипта; переходим событием `yt-navigate`.
- Документные уроки — PDF-мануалы, встроенные плагином PDF Embedder (в странице `pdfemb-data=<base64>`).
  Часть PDF почти без текста (картинки): конспекты по ним тонкие.
- 12 параллельных агентов Haiku подряд упёрлись в лимит сессии подписки (HTTP 429): волнами по 6.
- `heredoc` с `\n` или `\a` в Bash портит файлы (обратные слэши) — править через Edit/Write.
