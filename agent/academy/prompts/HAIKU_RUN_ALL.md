# Задача: дообработать уроки Academy и слить их в реестр знаний агента

Это единственная инструкция для запуска. Читайте её целиком, больше промптов открывать не нужно.
Вы работаете сами: читаете входы, пишете конспекты и уроки, запускаете три команды проверки и
слияния, в конце докладываете. Ничего не коммитите и не публикуете.

## 1. Зачем это

R-Pro («Рациональное производство») — российская сборка Visual Components 4.x; скрипты в ней на
встроенном **Python 2.7** (`vcScript`, `vcApplication`, `vcComponent`…), есть .NET-аддоны. К
R-Pro подключён локальный ИИ-агент на небольшой модели (qwen3 8B, контекст 8 тысяч токенов): он
ищет в базе знаний короткие фрагменты и отвечает по ним новичкам. Знания берутся из обучающих
материалов Visual Components Academy. Ваша работа — превратить ещё не обработанные материалы в
короткие **русские уроки** для этого агента (через английский конспект) и сложить их в
**единый реестр знаний**. Приёмы Visual Components в R-Pro работают, но функции версий 5.x и
Python 3 API в ней могут отсутствовать — это надо честно помечать.

## 3. Порядок работы

1. **Осмотр.** Выполните `python academy_status.py`, откройте `pending/index.json`: там `slug`,
   `kind` (lesson/webinar), `source` (video/pdf), `tokens`. Обрабатывать нужно **каждый** урок из него.
2. **По пачкам.** Берите пачки `pending/batches/*.json` по очереди (JSON-массив slug). Для пачки:
   - одним ответом (параллельные Read) прочитайте все `pending/lessons/<slug>.txt` пачки;
   - **стадия 1** (раздел 4): одним ответом (параллельные Write) запишите все `pending/out/en/<slug>.md`;
   - **стадия 2** (раздел 5): одним ответом прочитайте `pending/terms/<slug>.json` пачки (английские
     конспекты у вас уже в контексте) и запишите все `pending/out/ru/<slug>.md`;
   - переходя к следующей пачке, не держите в голове прошлые тексты. Если урок длиннее ~15 тысяч
     токенов (`tokens` в индексе), обрабатывайте его отдельно.
   Если вам доступен запуск субагентов, можно раздать пачки волнами **не более чем по 6**: каждому —
   «возьми пачку `<id>` и выполни пункты 2–3 по разделам 4–5 файла `prompts/HAIKU_RUN_ALL.md`»
   (12 параллельных однажды упёрлись в лимит подписки). Без субагентов делайте всё сами подряд.
3. **Проверка.** `python validate_digests.py en` и `python validate_digests.py ru`. Структурные
   замечания (нет раздела, нет строки применимости, остались метки времени) исправьте в самих файлах
   `pending/out/…`. Предупреждения «длинный» не блокируют.
4. **Слияние.** `python academy_consolidate.py --apply --model "<название вашей модели>"`.
   Скрипт сам проверит каждый урок, перенесёт принятые в реестр, сохранит исходные тексты в архив,
   пересоберёт поиск агента и проверит результат. Строки `ОТКЛОНЁН <slug>: причины` — урок не принят;
   исправьте файл в `pending/out/…` и запустите команду снова (можно повторять; принятые не
   дублируются). Если вывод заканчивается `ПРОВЕРКА НЕ ПРОЙДЕНА` — остановитесь и доложите дословно.
5. **Чистка.** Когда нет ни одного `ОТКЛОНЁН` и `pending/lessons/` целиком слит, выполните
   `python academy_consolidate.py --apply --clean`. Скрипт удалит рабочие папки (`pending/`,
   `digests_en/`, `digests_ru/`, `transcripts/`, `work/`) **только после проверки**; если он пишет
   `ЧИСТКА ОТМЕНЕНА, пока есть: …` — это не ошибка, а защита: устраните причину (обычно что-то ещё не
   слито) и повторите. **Ничего не удаляйте руками** и не обходите защиту.
6. **Итог.** `python academy_status.py` и доклад по форме из раздела 8. В рабочей папке после чистки
   не должно остаться ничего, кроме скриптов, `prompts/`, каталогов, `registry/` и сводок.

## 4. Стадия 1: английский конспект (`pending/out/en/<slug>.md`)

Вход — `pending/lessons/<slug>.txt`: шапка (`LESSON`, `CATEGORY`, `VISUAL COMPONENTS VERSION OF THE
LESSON`, оглавление страницы, `SOURCE`) и тело. Тело двух видов:
- **видео/вебинар** — `TRANSCRIPT` с минутными метками `[3:20]` в начале абзацев; это **распознанная
  речь**: код в нём «прочитан вслух» («vc dot delay», «stop movement»);
- **PDF-мануал** — `DOCUMENT TEXT` с метками страниц `[стр. 12]`; это написанный текст, имена точные,
  но рисунков и скриншотов в нём нет.

Формат файла (строго такой):

```
# <lesson title>
version: <VISUAL COMPONENTS VERSION OF THE LESSON> | category: <category> | source: <SOURCE url>
applicability: likely ok | check | no — <short reason, only when not "likely ok">

## Purpose
1-2 sentences: what the user learns and when the technique is needed.

## Steps
Numbered imperative steps, one action per line, with the exact UI names as spoken or printed.
Put the minute mark [3:20] (video) or page mark [p.12] (PDF) where the step is shown.
Keep exact values, numbers, names.
(For a reference-style PDF without a procedure, name this section "## Reference": one line per
property/statement/feature — name — what it does — default or allowed values.)

## Scripting / API
Only if the source mentions Python/.NET API: exact class, method, property and event names,
parameters, what they do; short code only if shown or dictated precisely. "none" if absent.

## Tips and pitfalls
One line each, starting "- TIP:" or "- PITFALL:", with the [m:ss] / [p.N] mark. The most valuable
part: shortcuts, non-obvious behaviour, warnings, "this will not work if…". Concrete, not generic.

## Keywords
10-15 comma-separated search terms a user might type, including exact API/UI names.
```

Правила:
- **Только то, что есть в источнике.** Не выдумывайте шаги, имена, числа, вызовы API. Сомневаетесь —
  опустите.
- Видео: идентификатор кода, восстановленный из речи, пишите в обратных кавычках и добавляйте
  `(from speech)`, если докладчик его не произнёс по буквам и его не подтверждают оглавление или имена
  файлов. Угаданное имя нельзя выдавать за точное. PDF: «(from speech)» не нужно.
- PDF: если шаг опирается на рисунок, пишите «see figure on [p.N]», не гадайте, что на нём.
- `applicability`: **check** — для Python 3 API (`import vc`, `async`/`await`, `OnRun`/`OnSignal`),
  всего, что показано только для Visual Components 5.x, и облачных функций; **no** — только если
  урок целиком про то, чего в R-Pro быть не может; иначе **likely ok**. Версия урока 5.x — повод
  для `check`.
- Длина: 200-400 слов (длинные до 500; справочные PDF и большие вебинары до 900). Без воды,
  приветствий и рекламы. Если материал почти пересказывает оглавление страницы — конспект короткий и
  с пометкой об этом. Если из PDF извлёкся лишь небольшой текст (в основном картинки) — так и
  скажите в `## Purpose`, не додумывайте.
- Вебинары длинные и разговорные: берите только содержательное (демонстрации, приёмы, ограничения).

## 5. Стадия 2: русский урок для агента (`pending/out/ru/<slug>.md`)

Вход — ваш английский конспект и `pending/terms/<slug>.json`: словарь «английское название
интерфейса → точное русское название в R-Pro» (из ресурсов самой программы). Агент читает один-два
таких урока за раз и ищет их по ключевым словам: урок должен быть коротким, самодостаточным и
содержать слова, которые напишет русскоязычный пользователь.

Формат (строго такой):

```
# <Название урока по-русски>
Источник: Visual Components Academy, «<English title>», версия <version>. Применимость к R-Pro: <скорее всего работает | проверить: <причина по-русски> | не применимо: <причина>>

## Задача
1-2 предложения: что это даёт и когда нужно.

## Как сделать
Нумерованные шаги, одно действие в строке, русские названия элементов в «ёлочках».

## Скрипты и API
Только если есть. Идентификаторы латиницей в обратных кавычках. Если в английском конспекте у
идентификатора стоит "(from speech)", перенесите пометку: «(восстановлено на слух, не проверено)».
Если раздела нет по существу — пропустите его целиком.

## Лайфхаки и ловушки
Строки «- Совет:» и «- Ловушка:». Самое ценное: не теряйте ни одной ловушки и ни одного
неочевидного приёма из английского конспекта.

## Ключевые слова
12-20 слов и фраз через запятую: русские слова, которые наберёт пользователь, русские названия
элементов, английские термины и имена API.
```

Применимость в строке источника: `likely ok` → «скорее всего работает», `check` → «проверить: …»,
`no` → «не применимо: …» (причину переведите).

Правила:
- **Терминология — главное.** Если шаг относится к элементу, который есть в `terms/<slug>.json`, пишите
  русское название из файла **дословно**, в «ёлочках»; если вариантов два через « / » — берите
  подходящий. Элемента нет в файле — переведите по смыслу и один раз добавьте английский оригинал
  в скобках: «Слой (Layer)». Не выдумывайте русское название и не выдавайте его за точное.
- Код, имена API/классов/методов/свойств, имена файлов, числа с единицами, горячие клавиши — без
  изменений, латиницей.
- **Только английский конспект.** Не добавляйте фактов, шагов и имён из собственных знаний, даже если
  уверены. Расплывчато в конспекте — расплывчато и в уроке.
- Уберите метки `[m:ss]` и `[p.N]`.
- Длина: **не больше 2500 знаков** на урок. Считайте **знаки, а не байты** (кириллица в UTF-8 —
  два байта на знак; прежние запуски на этом путались). Не помещается — сначала режьте очевидные
  шаги, лайфхаки и ловушки сохраняйте.
- Деловой технический русский, повелительное наклонение в шагах. Без приветствий, рекламы и
  «в этом уроке мы».
- Только markdown, никаких комментариев вне содержимого файла.

## 6. Границы

- Меняйте только файлы в `pending/out/en/` и `pending/out/ru/`. Всё остальное делают скрипты.
  Исключение — исправление ошибок конспекта, на которые указала проверка.
- Не трогайте `registry/`, `../kb/`, `../*.py` (код агента), `docs/`, `README.md`. Не запускайте
  `git`. Не создавайте в рабочей папке заметок и черновиков: промежуточное — только в системной
  временной папке.
- Не скачивайте файлы, не заходите в интернет, не запускайте захват YouTube: все входы уже на диске.
  Если входа не хватает (нет `pending/lessons/<slug>.txt`), назовите такой урок в докладе, не
  придумывайте его содержание.
- Если упёрлись в лимит подписки (ошибка 429 или «session limit») — остановитесь, ничего не ломая:
  готовые файлы в `pending/out/` останутся, команду слияния можно запустить в любой момент; доложите,
  на какой пачке встали.

## 7. Что считать выполненным

- Каждый урок из `pending/index.json` слит в реестр (в выводе слияния нет `ОТКЛОНЁН`), поиск агента
  пересобран, проверка пройдена, чистка выполнена без отмены.
- `python academy_status.py` показывает `ready: 0` (в `STATUS.md` нет раздела «Готовы к запуску»).

## 8. Доклад (в конце, по этой форме, без лишних слов)

```
Обработано: <N> из <M> (PDF: <n>, видео и вебинары: <n>)
Слито в реестр: <N>; отклонено и исправлено: <N>; не удалось: <список slug с причиной>
Применимость: likely ok <n> / check <n> / no <n>
В базе агента: уроков <n>, фрагментов <n> (строка вывода академии «уроков в базе…»)
Чистка: выполнена | отменена (<причина>)
Аномалии: <тонкие PDF, уроки без текста, расхождения; или «нет»>
Сколько пачек запускали и были ли ошибки лимита: <кратко>
```
