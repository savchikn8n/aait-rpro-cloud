# Конкурсное задание TechSkills 2026 в агенте

Разбор «Конкурсного задания» по модулям A, B, C (модуль D сознательно не включён — ведётся отдельно):
`general.md`, `module_a.md`, `module_b.md`, `module_c.md`. Разделы `## …` — единицы поиска.

Как попадает к модели и пользователю — `agent/contest.py`:
- по теме вопроса (манометр, OP50, Dobot, Yamazumi, «модуль A/B/C») к вопросу подкладываются критерии приёмки и ближайшие разделы
  (`chat._reference_note`); учитываются последние три реплики пользователя;
- команды без модели: `/задание`, `/критерии`, `/раскладка`, `/расчёт` (`intents.py`);
- те же разделы лежат в базе знаний: `python agent/contest.py` пересобирает `agent/kb/contest_chunks.jsonl`.

Строители прошлого теста (`rpro_pharma_plant`, `rpro_robot_cell`, `rpro_lean_optimize`, `rpro_techskills_field`) скрыты
(`RPRO_LEGACY_TECHSKILLS=1` включает): они заменяют сцену и решают другие задания.

После правки .md: `python agent/contest.py && python tests/test_contest.py`.
Что в тексте — выводы из задания, а не данные организаторов: числа Base5/Tool4/J1–J6 и номер команды в задании пустые, агент должен спрашивать.
