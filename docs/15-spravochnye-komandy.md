# 15. Справочные команды и проверенные ответы

*06.10.2026*

Агент на qwen3:8b отвечает на «как сделать…» за 30–100 секунд и регулярно
сочиняет: кнопки, которых нет, код на Python 3, «ловушки» из уроков. Правило в
подсказке модель не держит (см. [docs/14](14-obuchenie-po-urokam-academy.md)),
поэтому справка теперь выдаётся **кодом, без модели и без R-Pro** — за доли
секунды и только тем, что лежит в базе знаний.

## Команды

| Команда | Что делает | Откуда данные |
|---|---|---|
| `/справка <вопрос>` | 2–3 выдержки из справки R-Pro, справки API и уроков Academy; сверху — проверенный ответ, если вопрос совпал с записью faq; снизу — лучший совет из уроков | `kb/chunks.jsonl`, `kb/academy_chunks.jsonl`, `kb/faq.json`, `kb/tips.jsonl` |
| `/справка <название раздела>` | раздел целиком (название подсказывается в конце выдачи) | то же |
| `/справка уроки <вопрос>` | только уроки Academy | `kb/academy_chunks.jsonl` |
| `/api <имя>` | класс (`vcSimulation`) — свойства, методы, события; член (`setInitialState`, `vcMatrix.translateAbs`) — в каких классах и описание; оговорки R-Pro | `kb/api_index.json`, справка API, `faq.json → api_notes` |
| `/термин <слово>` | английское название из уроков ↔ русская подпись в R-Pro (4530 пар из ресурсов программы); бытовое слово → термин R-Pro | `kb/ui_terms.json`, `glossary.py` |
| `/совет [тема]` | советы из уроков (docs/12); без темы — список тем | `kb/tips.jsonl` |
| `/проблема [что случилось]` | проверенный ответ на частую неполадку; без слов — весь список | `kb/faq.json` |
| `/сброс` | очистить разговор (раньше в панели уходил модели как вопрос) | — |

Синонимы: `/спр`, `/апи`, `/перевод`, `/словарь`, `/лайфхак`, `/неполадка`, `/ошибка`.

Обычными словами тоже работает:
- «как по-русски Component Container?», «как в R-Pro называется feeder» → `/термин`;
- частые неполадки и рецепты («после сброса всё улетело в ноль», «не найдена
  лицензия», «как сделать брак после контроля», «как изменить скорость
  конвейера») → готовый ответ из `faq.json`, если совпал шаблон записи.

Просьбы-действия («поставь скорость всех конвейеров 300», «сделай ленту
быстрее», «исправь линию») готовым ответом **не перехватываются** — их делает
модель с инструментами. Но совпавшая запись faq подкладывается модели как
«проверенный факт» (`chat._reference_note`): так модель узнаёт имя свойства
`ConveyorSpeed`, а не гадает.

Ответы справочных команд не остаются в истории разговора (`intents.is_reference`):
длинные выдержки вытесняли бы из контекста 8B сам разговор.

## Как «лечить» повторяющиеся ошибки агента

1. В журнале `%LOCALAPPDATA%\R-Pro\AIAgentBridge\agent.log` видны вопрос, ответ
   и строка «→ справка подложена: …».
2. Если ошибка — в частом вопросе, допишите запись в `agent/kb/faq.json`:
   `title`, `keys` (слова для поиска `/проблема`), `patterns` (регулярные
   выражения по тексту в нижнем регистре, `ё→е`), `answer`. Только проверенное
   на R-Pro — запись отвечает вместо модели.
3. Проверка шаблонов без R-Pro:
   `python agent/quickref.py проблема <фраза>` и прогон фраз через
   `intents.handle` (просьбы-действия не должны совпадать).
4. Оговорка к имени API — в `api_notes` того же файла.

## Пересборка данных

```
python agent/quickref_build.py      # kb/ui_terms.json и kb/tips.jsonl
```

`faq.json` пишется руками. Установщик (`installer/build.ps1`) кладёт
`api_index.json`, `ui_terms.json`, `tips.jsonl`, `faq.json` рядом с базой.

## Заодно: «Агент запущен, но модель не загрузилась»

Причина (журнал Ollama 06.10): прогрев модели (`llm_ollama.warm_up`) не
передавал `num_ctx`, и Ollama 0.35, обновившаяся в то утро, грузила qwen3:8b с
контекстом по умолчанию 40960 — 11,6 ГБ, половина на процессоре; первый вопрос
(`num_ctx=8192`) всё равно её перезагружал. Вдобавок прогрев встал в очередь за
чужими запросами к видеокарте, через 300 с агент сдался и больше не пробовал.

Исправлено:
- прогрев передаёт тот же `num_ctx`, что и чат: 3,9 с, 6,2 ГБ, 100 % в видеопамяти;
- `serve._warm_up` повторяет загрузку (30 с, 60 с, … до 5 мин), ошибка в панели
  — понятными словами (видеокарта занята / Ollama не запущена / нет модели);
- панель после предупреждения ждёт и пишет «Модель загрузилась — можно спрашивать»;
- в приветствии панели — подсказка про `/справка` и `/помощь`.

Ядро панели пересобрано (`addon/build.ps1`), подхватится при следующем запуске
R-Pro; права администратора не нужны.
