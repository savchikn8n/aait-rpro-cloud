# Что внутри R-Pro

Результаты разбора установленной версии **R-Pro 2.2.2** (`C:\Program Files (x86)\RProv222`).
Это основа всех решений по архитектуре: где к программе можно «прицепиться» и какими средствами.

## Главный вывод

R-Pro («Рациональное производство», ООО «РПДС») — это переименованная сборка
**Visual Components 4.x** с ядром **KUKA.Sim**. Внутренние интерфейсы совпадают с
Visual Components вплоть до имён методов, отличаются только пространства имён:

| Visual Components      | R-Pro                          |
|------------------------|--------------------------------|
| `VisualComponents.Create3D`  | `RProSoftDigital1.Create3D`    |
| `VisualComponents.UX.Shared` | `RProSoftDigital1.UX.Shared`   |

Практический смысл: **вся документация, примеры кода и наработки сообщества Visual Components
применимы к R-Pro напрямую**. Это резко снижает цену разработки.

## Технический стек

- .NET Framework 4.5, WPF, Caliburn.Micro + MEF, Infragistics для интерфейса;
- встроенный **Python 2.7** (`python27.dll`, полный `lib`, `_socket`, `_ctypes`, `sqlite3`);
- рендер — DirectX, физика — NVIDIA PhysX, чтение CAD — ядра Adobe/AutoCAD/HOOPS;
- связь с оборудованием: OPC UA, Siemens S7, Fanuc, Stäubli, Universal Robots RTDE, KUKA KRC;
- лицензирование Guardant, сетевой ключ на отдельном сервере, порт 3189.

их можно разбирать сторонними средствами без запуска программы.

## Точка расширения № 1: Python-API (используем её)

Штатный механизм «Python Add-on». Папка с `__init__.py` кладётся в `My Commands`,
при старте программа вызывает `OnAppInitialized()`, где команда регистрируется
через `loadCommand()` и попадает на ленту через `addMenuItem()`.

Ключевые возможности `vcApplication` для агента:

| Метод / событие | Зачем нужен агенту |
|-----------------|--------------------|
| `Components`, `findComponent` | прочитать сцену, найти объект |
| `SelectionManager` | увидеть и задать выделение |
| `Simulation` (`run`, `halt`, `reset`, `SimTime`) | управлять симуляцией |
| `getMessages`, `clearMessages` | читать панель вывода: ошибки и предупреждения |
| `beginFrameGrab` / `executeFrameGrab` / `endFrameGrab` | **сохранить снимок 3D-вида в файл** |
| `messageBox` | показать пользователю сообщение |
| `rayCast` | геометрические проверки |
| `OnIdle`, `OnRender`, `OnComponentAdded`, `OnSelectionPostChange` | узнавать о происходящем |

Ограничения, которые определили конструкцию моста:

1. **API можно трогать только из главного потока.** Поэтому HTTP-сервер лишь
   складывает задания в очередь, а выполняет их главный поток.
2. **`OnIdle` помечен в справке как устаревший.** Подстраховываемся: подписываемся
   и на `OnIdle`, и на `OnRender`, а из фонового потока будим цикл сообщений Windows
   пустым сообщением через `ctypes` — это безопасно, потому что трогается WinAPI, а не API R-Pro.
3. **Python внутри — 2.7.** Современные библиотеки работы с моделями туда не поставить,
   поэтому логика агента живёт во внешнем процессе на Python 3.

## Точка расширения № 2: .NET-плагины (фаза 3)

Программа при запуске ищет и загружает сборки по маскам `UXAddOn.*.dll`, `Plugin.*.dll`,
`rpro.Conn.*.dll`, `rpro.cat.*.dll` из своей папки.

Плагин — это класс, реализующий `RProSoftDigital1.UX.Shared.IPlugin`:

```csharp
void Initialize();
void Exit();
```

Через MEF ему доступны `ICommandRegistry` (кнопки на ленте и панели команд),
`IApplication`, `ISelectionManager`, `ISimulation`, `IMessageService`, `IRenderService`.
Это путь к полноценному окну чата внутри программы.

Издержки: интерфейсы недокументированы (нужен разбор через ILSpy — самый компактный
образец `UXAddOn.Modeling.dll`, всего 10 КБ), копирование в `Program Files` требует прав
администратора, а обновление R-Pro может сломать совместимость.

## Что проверено, а что нет

Проверено разбором файлов и рефлексией по сборкам: структура API, места загрузки
расширений, сигнатуры методов, формат проектов.

Не проверено на живой программе до первого запуска моста: реально ли срабатывает
`OnIdle`/`OnRender` как «прокачка» очереди и какие строки формата принимает
`beginFrameGrab`. В коде моста на этот случай сделан перебор вариантов
(`rpng`, `png`, `rjpegstd`, `rbmp`) и подстраховка через пробуждение цикла сообщений.
