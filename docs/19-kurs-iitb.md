# Курс ИИТБ Skill Camp: обучение агента и практика

Источник: <https://iitb.ru/for-students/> (страница под логином; открывается в Chrome пользователя). Курс по
R-Pro 2.1.x на русском: 16 видеоуроков с PDF-заданиями («Цифровое производство»), урок 18 (Lean Six Sigma) без
задания; у «Урока 17» видео нет. Роботизированная сварка, аддитивное и складская логистика — «видеокурсы в разработке».

## Как видео стали знаниями агента

1. `agent/iitb/fetch_media.py` — скачивает 17 mp4 (~4 ч) и 16 PDF (через `curl`: корпоративная подмена сертификатов
   ломает SSL у Python).
2. `agent/iitb/transcribe.py` — «уши и глаза»: faster-whisper large-v3 на GPU (≈ в 5 раз быстрее реального времени) даёт
   стенограмму с таймкодами; opencv режет ключевые кадры (смена сцены или раз в 25 с) и собирает листы 2×2, которые
   просматривает Claude. В видео вшиты английские субтитры, интерфейс на кадрах читается.
3. `agent/iitb/lessons/L01…L18.md` — конспекты по стенограммам и кадрам: суть, шаги с названиями кнопок, ловушки, ключевые
   слова, условия практического задания.
4. `agent/iitb/iitb_to_kb.py` → `agent/kb/iitb_chunks.jsonl` (123 фрагмента, source `iitb`); `kb.py` подхватывает его
   рядом с Academy, без скидки на оценку. Поиск: `/справка курс <вопрос>`, `rpro_help(source="курс")`.
5. `agent/kb_api_extra.py` → `agent/kb/api_extra.json`: 73 класса Python-API, которых нет в автодополнении
   (дашборд статистики, процессы, аниматор камеры…); `/api vcStatisticsChart` теперь отвечает.

## Практика: задания кодом

`python agent/iitb/runner.py N` — очищает сцену, выполняет `agent/iitb/tasks/lessonNN*.py`, проверяет прогоном и пишет
`examples/iitb/Урок_N.rpro` (+ снимок в `shots/`, видео/PDF/CSV там, где этого требует урок).
Команд у курса нет — агент подхватывает знания из диалога сам (`agent/iitb/course.py`, `chat._reference_note`):

- **Вопрос «как …»** по теме урока («как настроить ожидание сигнала у дверей станка?») — ответ из проверенных записей
  `kb/faq.json` и конспектов уроков; в каждом конспекте есть раздел «Как это делает агент (проверено в R-Pro 2.2.2)»
  с рабочим кодом для `rpro_exec` и ловушками (пишется `agent/iitb/add_recipes.py`, база — `iitb_to_kb.py`).
- **Просьба построить учебную сцену** («собери роутер», «сделай станок с дверями по сигналу», «построй склад с краном-штабелером»,
  «запаллетируй банки», «сделай позиционер») — агент выполняет задание урока кодом; если в сцене что-то есть, спросит «да».
- **Просьба к сцене пользователя** (видео, дашборд статистики, детектор столкновений, подготовка ячейки) — задание не
  запускается (оно заменило бы сцену): модели подкладывается рецепт урока, и она делает это в текущей сцене через `rpro_exec`.
- «Выполни задание урока 15» / «объясни урок 5» понимаются, но слова об уроке не обязательны.

Проверка — `python agent/eval_course.py [L14 L11 …]` (живой агент и R-Pro; результат в `agent/eval_course_result.json`).

## Что выяснено на R-Pro 2.2.2

Подробности и ловушки — в памяти проекта (`rpro-iitb-practice`); главное:
видео пишет рекордер как `.avi` (имя файла задавать без расширения, `mp4` делаем ffmpeg-ом);
`createNode(VC_NODE, имя)` без типа возвращает `None`; точки робота — `Positions[0].setJoints([...])`;
положение датчика вдоль ленты — `ComponentPathSensor.Distance`; узел на ленте: `TransportIn Source="From Container"`,
`TransportOut Destination="To Container"`; присваивание свойств `MoveJoint` (`Controller`/`Joint`) в коде может подвесить
поток моста — R-Pro при этом жива, мост молчит (в этом случае помогает перезапуск R-Pro).
