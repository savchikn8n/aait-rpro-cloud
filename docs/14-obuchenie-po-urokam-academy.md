# Обучение агента по урокам Visual Components Academy

R-Pro — это Visual Components 4.x под своим именем, поэтому приёмы из обучающих видео
Visual Components в ней работают. Видео смотреть дорого по лимитам подписки, поэтому
агент учится не по видео, а по **тексту их субтитров**: из него модель Haiku делает
конспекты, а они превращаются в короткие русские уроки в базе знаний агента.

Технические подробности запуска и ловушки конвейера — в
[agent/academy/README.md](../agent/academy/README.md). Лайфхаки одним списком для
людей — в [docs/12-lajfhaki-rpro.md](12-lajfhaki-rpro.md).

## Что получилось

| Этап | Результат |
|---|---|
| Каталог портала | 265 уроков, у 222 есть видео, у 152 — файлы для скачивания |
| Транскрипты | все 222 ролика уроков, плюс 7 вебинаров; для первых 221 — 42,8 часа и около 865 тыс. токенов текста |
| Названия интерфейса | 8985 пар «английское — русское» из ресурсов самой R-Pro (`Resource.English.dll` и `Resource.Русский.dll`) |
| Конспекты и уроки | 272 урока в реестре: 220 из первого прогона (5 октября, Haiku 4.5) и 52 из второго (8 октября, Haiku 5.5: 43 PDF-мануала, 7 вебинаров, 2 перезахваченных урока) |
| В базе агента | 269 уроков → 630 фрагментов (`agent/kb/academy_chunks.jsonl`), исключено 3 (Python 3 API, не применимо к R-Pro ×2) |
| Для людей | 497 лайфхаков по 19 темам, со ссылками на уроки |

Работа шла в четыре стадии: транскрипт → английский конспект (Haiku) → русский урок
(Haiku, названия интерфейса строго из ресурсов R-Pro) → оценка (Sonnet). Ориентировочно
это около 5 млн токенов Haiku и около 0,8 млн токенов Sonnet, всё без просмотра видео.

## Единый реестр знаний

Обработанные уроки не лежат россыпью файлов: всё собрано в `agent/academy/registry/`.

- `lessons.jsonl` — по строке на урок: русский урок, английский конспект, метаданные (версия,
  категория, ссылка), применимость к R-Pro, вошёл ли урок в базу агента и почему нет, какая модель и
  когда обработала, оценка аудита, если урок проверялся.
- `sources.jsonl.gz` — исходные тексты (транскрипты с минутами, текст PDF, сырые субтитры): по ним
  проверяют и правят уроки; получить их заново можно только захватом через Chrome.
- `audit/` — отчёты оценки качества.
- Поиск агента (`agent/kb/academy_chunks.jsonl`) строится из реестра и пересобирается идентично.

Рабочие папки (`pending/`, `transcripts/`, `digests_*`, `work/`) нужны только на время обработки.
Новые материалы обрабатывает единый промт [agent/academy/prompts/HAIKU_RUN_ALL.md](../agent/academy/prompts/HAIKU_RUN_ALL.md):
модель делает конспекты и уроки, скрипт `academy_consolidate.py` сливает их в реестр, проверяет и
только потом чистит рабочие папки.

## Как агент использует уроки

- Фрагменты уроков ищутся тем же поиском, что и справка, и **включены по умолчанию**.
  Выключить: переменная `RPRO_KB_ACADEMY=0`. Искать только по урокам: `rpro_help` с
  `source="уроки"`.
- Защиты от вытеснения справки: в подложенных к вопросу двух фрагментах не больше одного
  урока; оценки уроков умножаются на 0,85 (`RPRO_KB_ACADEMY_WEIGHT`).
- Если подложен урок, модели сказано: названия кнопок сверять со справкой и лентой, код
  для `rpro_exec` писать только на Python 2.7.
- Уроки про Python 3 API (`await`, `import vc`) и «не применимые к R-Pro» в базу не
  попадают (в реестре у них `in_kb: false` и причина). Уроки, записанные для версий, где
  функции может не быть, остаются с пометкой «⚠ проверить применимость к R-Pro».
- Имена Python-API в уроках сверены с `agent/kb/api_index.json`: регистр исправлен
  автоматически (190 правок), имена, которых нет в API R-Pro, помечены ⚠.
- Какие фрагменты подложены к ответу, видно в трассировке чата строкой
  «→ справка подложена: …».

## Что показала оценка

Оценивали модели Sonnet по исходным транскриптам, без ручного разбора.

- **Поиск (25 вопросов новичка).** Релевантность подложенных фрагментов выросла с 1,44
  до 2,32 из 3: лучше в 11 вопросах, хуже в 2 (там урок вытеснил профильную справку),
  в 12 без разницы. Без ограничения «один урок на два слота» уроки вытесняли справку в
  36 случаях из 50, поэтому оно встроено.
- **Верность (16 случайных уроков, два судьи).** В среднем около 3,2 из 5, полезность
  около 2,8 из 5. Типичные ошибки: придуманные «ловушки», перепутанные кнопки, потерянные
  ключевые шаги, имена API и .NET-библиотек, восстановленные на слух, смесь русских и
  английских названий интерфейса. Это малая выборка, а сам транскрипт получен из речи,
  так что цифры — ориентир, а не измерение.
- **Живая модель (4 вопроса, `qwen3:8b`, моста R-Pro не было).** Паллетизация: вместо
  ответа мимо — связный ответ из урока. «Скрыть компонент»: без уроков запрос ушёл в
  таймаут 10 минут. «Кнопка-свойство»: модель и с уроком сочинила код. Вывод: 8B не
  следует фрагментам надёжно, уроки дополняют готовые команды в коде, а не заменяют их.

**Второй прогон (52 урока, Haiku 5.5, единый промт).** Все 52 приняты слиянием с первого раза,
русские уроки короче прежних (медиана 2101 знак против 3089, максимум 2504 против 11 562: лимит на
знаки соблюдён). Ни один идентификатор из «Скриптов и API» не отсутствует в исходном тексте (у
первого прогона таких 13%; сравнение приблизительное: новые уроки в основном из PDF). Аудит 8 уроков
по исходникам (судья Sonnet): верность в среднем 4,25 из 5, полезность около 3,1; «keep» — 2, «fix» —
5, «drop» — 1: `mqtt-client-tutorial` (функция Visual Components 5.0, в R-Pro её нет) переведён в
«не применимо» и из поиска агента выведен. Остальные замечания — версии: часть возможностей PDF
4.10 (`AllowIdling` и др.) в более старых сборках, скорее всего, нет.

Масштаб риска: 162 из 218 уроков не содержат кода и имён API (описания кнопок и
последовательностей). Код есть в 56 уроках, и именно там неточность опаснее: агент
выполняет Python прямо в сцене.

## Что делать, если агент дал плохой совет

В папке `agent/academy`:

1. В трассировке найти строку «→ справка подложена: …» и название урока; найти его slug:
   `python academy_lesson.py find <часть названия>`.
2. Показать урок вместе с исходным текстом для сверки:
   `python academy_lesson.py show <slug> --source`.
3. Исправить русский урок в файле и вернуть его в реестр с пересборкой базы агента:
   `python academy_lesson.py set <slug> <файл.md>`.

Исправление одного урока обходится примерно в 6 тыс. токенов, это дешевле, чем проверять
все заранее.

## Чего пока нет

- Автоматической проверки и правки уроков по транскриптам. Для 56 уроков с кодом это
  около 0,1–0,15 млн токенов на Sonnet, для всех — около 1 млн.
- Файлов к урокам: в 152 уроках есть ZIP со сценами и скриптами, они не скачаны.
- Материала про достижимость робота, создание захвата и контейнер как поведение: поиск
  не нашёл ответа ни в справке, ни в уроках. Ещё поиск не находит `model-a-cartesian-robot` по
  слову «картезианский» (в уроке «декартов…»): нужна запись в `agent/glossary.py`.
- Проверки уроков второго прогона шире 8 проверенных: остальные 44 не аудировались.
- Состояние всех уроков: [agent/academy/STATUS.md](../agent/academy/STATUS.md); новые материалы
  обрабатываются единым промтом
  [agent/academy/prompts/HAIKU_RUN_ALL.md](../agent/academy/prompts/HAIKU_RUN_ALL.md).
